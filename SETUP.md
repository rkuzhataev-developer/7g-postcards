# Запуск в новом проекте (Claude Code в облаке)

## 1. Залить файлы в репозиторий
github.com/rkuzhataev-developer/7g-postcards → **Add file → Upload files** → перетащить всё содержимое этой папки
(включая папки `cards`, `thumbs`, `scripts`) → Commit to `main`.
Файл `.nojekyll` может не перетащиться (скрытый) — новая сессия создаст его сама.

## 2. Открыть сессию
claude.ai/code → новая сессия → репозиторий `rkuzhataev-developer/7g-postcards`.
В настройках окружения включить коннекторы **Figma** и **Microsoft 365**, а в сетевом доступе разрешить `www.figma.com` и `*.github.io`.

## 3. Первое сообщение в сессии
> Прочитай CLAUDE.md. Создай `.nojekyll`, если его нет, включи GitHub Pages (ветка main, корень), дождись публикации и проверь, что сайт открывается. Потом создай ежедневную задачу по тексту из SETUP.md (раздел 4) и пришли мне ссылку на сайт.

## 4. Текст ежедневной задачи
Расписание: по будням в 10:00 Asia/Almaty (`CRON_TZ=Asia/Almaty 52 9 * * 1-5` — с небольшим сдвигом, либо ровно `0 10 * * 1-5`).

> Выполни ежедневную публикацию открыток 7Generation строго по разделу «Ежедневная публикация» в CLAUDE.md этого репозитория: проверь таблицу на сегодняшние даты (в пятницу — и на выходные), добавь готовые открытки из Figma на сайт без сжатия, запушь, дождись обновления GitHub Pages и отправь одно сообщение в ветку Teams с отметкой Айданы и ссылкой на дату. Неготовые открытки и любые ошибки — уведомлением Родиону. Пиши по-русски. Таблицу не редактируй.

## 5. После первого успешного запуска
Сказать в старом проекте (Cowork «Selebrations 7g»), чтобы старую задачу отключили.
