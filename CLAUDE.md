# 7Generation Postcards — сайт и ежедневная публикация

Этот репозиторий — статический сайт на GitHub Pages с готовыми праздничными открытками 7Generation
и инструкция для ежедневной автоматизации. Отвечай пользователю (Родион, графический дизайнер 7G) по-русски.

- Репозиторий: `rkuzhataev-developer/7g-postcards`, ветка `main`, Pages из корня ветки `main`.
- Адрес сайта: https://rkuzhataev-developer.github.io/7g-postcards/
- Ссылка на конкретную дату: `https://rkuzhataev-developer.github.io/7g-postcards/#YYYY-MM-DD`

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Вся страница (HTML+CSS+JS в одном файле). Интерфейс на английском. Данные читает из `data.json`. |
| `data.json` | Список открыток. Единственное, что меняется при ежедневной работе (плюс картинки). |
| `cards/<id>-<lang>.png` | Оригиналы из Figma, PNG x2 (2160×2160), **без сжатия**. Скачиваются кнопкой Download PNG. |
| `thumbs/<id>-<lang>.jpg` | Миниатюры 480px JPEG q82 — только для превью на странице. |
| `scripts/add_card.py` | Скачивает PNG по ссылке экспорта Figma, делает миниатюру, дописывает `data.json`. |
| `.nojekyll` | Отключает Jekyll на Pages. |

### Формат записи в `data.json`
```json
{"id":"tr-2026-10-29","date":"2026-10-29","holiday":"Republic Day","country":"🇹🇷 Turkey",
 "images":[{"lang":"RU","src":"cards/tr-2026-10-29-ru.png","thumb":"thumbs/tr-2026-10-29-ru.jpg",
            "file":"7G Turkey Republic Day RU.png","w":2160,"h":2160,"bytes":5149556}]}
```
- `id` = ISO-код страны (2 буквы, строчные) + `-` + дата. Если в один день у одной страны два праздника — добавь суффикс (`kr-2026-10-03-2`).
- `holiday` и `country` — **по-английски** (переводи из таблицы). Флаг берётся из таблицы.
- `file` — имя скачиваемого файла: `7G <Country> <Holiday> <LANG>.png`, латиницей, без апострофов.

## Ежедневная публикация (по будням, 10:00 Asia/Almaty)

1. Сегодняшняя дата и день недели в Asia/Almaty (`TZ=Asia/Almaty date`).
2. Целевые даты: сегодня; если пятница — ещё ближайшие суббота и воскресенье.
3. Прочитай таблицу, найди строки на целевые даты.
4. Для каждой **готовой** строки:
   - если открытки с таким `id` ещё нет в `data.json` — выгрузи из Figma и добавь:
     `pip install pillow` (если нужно), затем
     `python3 scripts/add_card.py --id … --date … --holiday "…" --country "…" --lang RU|EN --file "…" --url "<export.url>"`
     (по разу на каждый язык);
   - закоммить и запушь в `main`: `git add -A && git commit -m "Add postcards YYYY-MM-DD" && git push`;
   - подожди 1–2 минуты и проверь, что `https://rkuzhataev-developer.github.io/7g-postcards/data.json` отдаёт новую запись
     (и что PNG по адресу `.../cards/<id>-<lang>.png` открывается). Если сайт не обновился за ~5 минут — уведомление Родиону, в Teams не писать.
     Если сеть сессии вообще не пускает на `rkuzhataev-developer.github.io` (прокси отвечает 403 на CONNECT) — это не ошибка публикации:
     после успешного push подожди 2 минуты и продолжай, а в итоге ответа отметь, что сайт проверить не удалось.
5. Отправь **одно** сообщение ответом в ветку Teams — `teams_reply_channel_message`:
   - teamId = `78c11fcd-c386-4387-820b-a236c72f333e`
   - channelId = `19:06a2e47bfadc4bb0957bccfc7dda501c@thread.tacv2`
   - messageId = `1790227317449`
   - bodyType = `html`
   - mentions = `[{"id": "f4ef0425-ded7-4fae-85b3-696687131bf1", "displayName": "Aidana Kabdykaparova"}]` — обязательно (упоминание добавится в конец).
   - Сообщение — **на английском**. Без текста открытки. Праздник и страна — по-английски, как в `data.json` (`holiday`, `country` с флагом).
     Дата — «October 29» (месяц полностью, без года).
   - Формат:
     - один праздник сегодня:
       `<p>🎉 Today, October 29 — Republic Day (🇹🇷 Turkey)<br>The postcard is ready to publish 👇<br>🖼 Download: <a href="https://rkuzhataev-developer.github.io/7g-postcards/#2026-10-29">open the postcard</a></p>`
     - праздник в выходной (в пятницу): вместо «Today, …» — «On Saturday, October 31 — …» / «On Sunday, November 1 — …». Никаких пояснений «публикуем заранее».
     - несколько праздников на одну дату:
       `<p>🎉 Today, December 16:<br>• Victory Day (🇧🇩 Bangladesh)<br>• National Day (🇧🇭 Bahrain)<br>The postcards are ready to publish 👇<br>🖼 Download: <a href="…/#2026-12-16">open the postcards</a></p>`
     - в пятницу с праздниками на разные даты — по блоку на каждую дату в одном сообщении, у каждого блока своя ссылка `#YYYY-MM-DD`.
   - Тестовый запуск (если в задаче сказано «ТЕСТ»): то же сообщение, но **без** mentions и с префиксом `🧪 TEST, please ignore. ` в начале.
6. Если на целевую дату праздник есть, но открытка **не готова** (статус не тот или нет ссылки Figma) — в Teams про неё не писать,
   отправить Родиону уведомление: «Открытка не готова: <дата> — <праздник> — <страна> (статус: <статус>)».
7. Если таблица не открылась, Figma не отдала картинку, push не прошёл, сайт не обновился или Teams не принял сообщение — уведомление Родиону с описанием ошибки.
8. Если на целевые даты праздников нет — ничего не отправлять, ответ одной строкой «Сегодня публикаций нет». Если всё прошло успешно — без уведомления, короткий итог в ответе.

Уведомления Родиону: **всегда** письмо на r.kuzhataev@7g.team через Microsoft 365 (`outlook_send_mail`) с темой «Открытки 7G: …»
(задача работает без открытого компьютера, push может не дойти). Дополнительно можно отправить PushNotification, если он есть в сессии.

## Правила

- Оригиналы PNG никогда не сжимать и не перекодировать.
- Таблицу не редактировать.
- Не дублировать записи: перед добавлением проверь `id` в `data.json`; повторный запуск `add_card.py` с тем же id+lang заменяет картинку.
- Дизайн страницы меняй только по просьбе Родиона. Цвета — токены в `:root`, есть тёмная тема.
